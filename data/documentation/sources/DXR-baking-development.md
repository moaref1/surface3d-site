# DXR baking: implementation and remaining work

The original standalone second baker uses D3D12 DXR 1.1 inline ray queries on the viewport adapter. No DLSS or viewport-renderer rewrite. Existing D3D11 compute and CPU baking remain available. This is a development implementation, not a claim of full Painter/Toolbag parity.

## Implemented

- Auto / Existing GPU compute / DXR hardware rays / CPU selector in Bake > Maps. Save preferences preserves the choice. Engine is machine-specific, not stored in portable project data.
- Hardware high-to-low projection, retaining front/rear distances, imported cages, name matching and per-triangle backface rules.
- Hardware AO, bent-normal, thickness and curvature rays; shared map formulas and edge reconstruction with the existing compute engine.
- Cached device-local triangle metadata and BLAS/TLAS, reused until prepared source geometry changes. Projection hits feed all requested compatible maps within the job.
- Bounded 8192-sample buffers; additional sample-work bounds for secondary rays. No full-resolution GPU AA packet allocation.
- Available-memory headroom check before large acceleration structures; dedicated worker device and serialized queue, responsive cancellation between bounded packets.
- Explicit rejection of software-adapter hardware acceleration; startup capability/compiler-resource failures select existing compute or CPU. Single-set DXR runtime failure retries compute, then CPU, with a log reason. Multi-set runtime failure retains the existing logged CPU retry.
- Actual completed engine, timings, GPU batch count and buffer allocation reporting. Release bake cache frees both engines' derived buffers.
- Existing selective-map retention, Bake changed, progressive previews, automatic baked-map publication and cage/seam diagnostics remain in use.
- Compiled shader binaries generated by Windows SDK DXC at build time. No DXC DLL needed at runtime; keep shaders/bake-dxr.cso and bake-dxr-primary.cso with the app.

## Measured on NVIDIA GeForce RTX 5050

Release build, original synthetic fixtures. Timings vary between runs and do not predict arbitrary production meshes.

| Fixture | Reference | DXR | Accuracy |
|---|---:|---:|---|
| 4096 normal, 32,768 high triangles, AA1, 4px padding | CPU 1677 ms | 1421 ms; cached 1339 ms | Byte-identical normal and hit/miss counts |
| 1024 pipe AO + curvature + bent normal, 32 rays | Existing GPU compute 818 ms | 104 ms | Maximum one RGBA8 level difference |
| 4096 pipe AO + curvature + bent normal, 32 rays | Not benchmarked against reference at this size | 1264 ms | Completed successfully; smaller-size numerical oracle checked |

Recorded buffer allocations: about 7.5 MiB for the plane projection fixture and 1.7 MiB for the pipe secondary fixture, excluding document maps, CPU staging and viewport allocations. These are allocation accounting, not a measurement of total dedicated VRAM. Ten focused bake/core/native/4K tests passed before the final software-adapter check was added; final verification is recorded separately.

## Remaining from the full request

- Painted local cage offsets and skew correction, undo/persistence and hard-edge protection.
- True affected-region/tile rebaking. Current selective rebaking works at whole-map granularity.
- Persistent projection-hit reuse between separate bake jobs; current reuse is within a job, with acceleration geometry cached across jobs.
- Full GPU-resident map accumulation and queued preview/readback; current bounded batches synchronize for readback.
- Higher-precision generated bake maps: current outputs are RGBA8. A higher-bit-depth export container cannot recover missing source precision.
- Full UDIM bake routing, bevel shader transfer, material/vertex-color ID sources and source-material transfer.
- Adaptive sampling/optional map-aware denoising, after independent quality tests; no hidden smoothing of projection errors.
- Actual AMD/Intel/older NVIDIA/low-memory hardware validation. DXR uses capabilities rather than vendor checks; this machine verifies NVIDIA only. DXR 1.0 without 1.1 uses the existing path.
