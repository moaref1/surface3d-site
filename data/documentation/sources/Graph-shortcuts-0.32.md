# Graph keyboard shortcuts

Click or hover the node graph to use its local shortcuts. Shortcuts pause while a text field or popup is active, or while dragging.

| Key | Action |
|---|---|
| N / B / L / M | Add Noise / Blur / Levels / Blend |
| T / V / H / I | Add Image Color / Voronoi / Height to Normal / Invert |
| O / P / U | Add Texture Output / Paint / Coordinates |
| Q / R / S / W | Add Color Ramp / Remap / Scalar / Warp |
| Y / Z / G | Add Wave / Reroute / Gradient |
| Arrow keys | Select the nearest node in that direction; hold Shift to add to selection |
| Tab / Shift+Tab | Select the next / previous graph node |
| E / F / F2 / Space | Disable or enable selection / frame selection / rename / preview |
| Shift+A or F3 | Search and add a node |
| / or ? | Show this shortcut list |

Ctrl and Shift editing shortcuts remain available. Keys reserved for app navigation and the viewport view wheel stay with those controls outside the graph.
