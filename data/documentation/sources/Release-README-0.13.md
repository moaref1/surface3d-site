# Surface3D 0.13

Run Surface3D.exe in this folder. Keep assets, shaders, shader-cache and licenses beside it.

Added: direct number entry (double-click/Ctrl-click or Window → Show numbers as text fields), neutral default materials/nodes, 50 grouped ready generators/effects, saved XYZ links/locks, connected 3D brush footprints, configurable edge padding and bake UV-overlap/gutter diagnostics. Generators can be clicked or dragged onto a layer/mask/channel and edited in Paint; Graph remains optional.

Read docs/Surface3D-0.13-artist-guide.md and docs/Surface3D-0.13-artist-tests.md. The complete catalogue is docs/Ready-generators-0.13.md. Earlier projects load; saving uses schema 14. Examples are demonstrations, not default templates.

35 development checks passed. Package-specific verification is in Verification.md. The larger missing-feature areas remain open in docs/Iteration-0.13-plan.md; this is not full Painter/Designer parity. One UV atlas at 256–2048, eight layers/flat folders, PNG8 export, bounded 128² physics, UV-neighborhood spatial filters and CPU primary bake projection remain current limits.
