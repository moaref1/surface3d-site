# Surface3D 0.14

Run Surface3D.exe in this folder; keep assets, shaders, shader-cache and licenses beside it.

Added: searchable texture grid/list, adjustable thumbnails, multi-image import, Explorer file drops, detected texture packs with channel review/exclusions, reusable material library, export material.s3dpack + eligible embedded material.s3mat, and a default original neutral HDR studio.

All earlier Paint, Graph, Bake, fifty-recipe and typed/XYZ/seam features remain. Projects still use schema 14. Earlier release packages remain separate. Read docs/Surface3D-0.14-artist-guide.md, docs/Surface3D-0.14-artist-tests.md and docs/Missing-features-0.14.md. The package-specific results are in Verification.md.

Current constraints: one UV atlas, 256–2048 texture resolution, eight layers/flat folders, sixteen embedded RGBA8 images, synchronous PNG8 export, bounded 128² physics, UV-neighborhood filters and CPU primary projection. No complete Painter/Designer parity is claimed.
