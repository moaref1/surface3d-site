# Surface3D 0.15

Run Surface3D.exe. Keep assets, shaders, shader-cache and licenses beside it. This original Windows/D3D11 texturing prototype adds the layered procedural app icon, semantic UI symbols and compact controls while retaining the charcoal/teal theme and existing workflows.

Read docs/Surface3D-0.15-artist-guide.md, Verification.md and docs/Missing-features-0.14.md. Review the PNG previews before testing. Broader production limitations remain; this is not a claim of full Painter/Designer parity.
