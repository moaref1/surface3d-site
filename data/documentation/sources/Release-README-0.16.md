# Surface3D 0.16

Open **Surface3D.exe** in this folder. Keep shaders, assets, runtime DLLs and licenses beside it. This is the standalone Windows development build for the combined master plan.

Use File → Import / Ctrl+I for meshes, textures and detected material packs. Use Paint for layers and masks; fill Properties has Channels / Coordinates / Effects. Bake can publish maps across material sets. Rendering beside Bake adds cameras, lighting, image output and color controls. Export retains Settings / Output templates / List of exports. Poly Haven is a category in Assets; downloading and applying are separate actions.

Read [the artist guide](docs/Surface3D-0.16-artist-guide.md) for controls, precision, known limits and the checks to try with your meshes. [Verification](Verification.md) records the tested executable, hardware and actual checks. Previous released projects remain readable; save an upgraded copy before editing important work.

This iteration retains existing nodes, simulation brushes, 50 recipes, editable graphs and branding. Ray/hybrid rendering, DLSS/denoising, camera effects, video, decals/stencils/text and viewport gizmos remain tracked work in docs/Rendering-and-artist-roadmap.md.
