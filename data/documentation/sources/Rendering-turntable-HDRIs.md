# Turntable and Poly Haven HDRIs

Rendering > Scene > Camera now includes Turntable: Play/Pause, signed speed in degrees per second and return-to-start. It orbits the camera horizontally around the current scene target, leaving lighting fixed. Mouse navigation and presentation exports temporarily pause playback; other workspaces do not advance it. This is preview playback, not video/sequence export.

Rendering > Scene > Environment has Poly Haven HDRIs. The separate dockable browser reuses visual thumbnails, search/category filters, 1K/2K HDR selection, download progress/cancellation and cached/offline assets. Select, download, then Use environment; no accidental application on single-click. The environment path is saved in the project through the existing workflow. Powered by Poly Haven attribution remains visible. Network availability and the existing HDR cache are required for uncached downloads.
