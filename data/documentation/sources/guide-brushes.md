# Brushes and tools

## The tools

| Key | Tool | What it does |
|---|---|---|
| **B** | Brush | Paints every channel that is switched on |
| **E** | Eraser | Takes paint away. Holding **Shift** with the brush also erases. |
| **U** | Smudge | Pushes paint around |
| **Shift+U** | Blur | Softens paint or a mask |
| **K** | Clone stamp | Copies one part of the texture onto another |
| **G** | Fill | Fills a connected area |
| **Q** | Mask / material | Switches between painting the mask and the material |
| **I** | Eyedropper | Picks a colour or value |
| **V** | Decal | Places an image on the model |
| **P** | Spline strokes | Paints along a curve. See [Splines and particles](guide-splines-particles.md). |
| **W** | Particles | Paints with a particle simulation. See [Splines and particles](guide-splines-particles.md). |
| **Y** | Sculpt | Sculpts into the normal map. See [Sculpting](guide-sculpting.md). |

## Brush size, hardness and angle

| Key | Action |
|---|---|
| **[** / **]** | Smaller / bigger |
| **Shift+[** / **Shift+]** | Softer / harder |
| **Ctrl+[** / **Ctrl+]** | Rotate the tip by 15 degrees |
| **Caps Lock** | Precise cursor |
| **Shift+M** | Mirror X on or off |
| **X** | Swap colours (on a mask: black and white) |
| **D** | Reset colours |

You can also drag with **Ctrl** and the left or right mouse button to change size, hardness, rotation or roundness. Which drag changes what is set in **Preferences > Shortcuts**.

## Pen pressure and smoothing

Pen pressure, symmetry, smoothing and stencils are in **Brush Settings** (**F5**). Gradients can run along a stroke.

## Brush files

A brush can carry an image tip, a stroke strip, invert and lighten modes, a projection and a tiled stencil. Brushes live in the **Brushes** panel (**F6**); **Ctrl** + wheel there changes the thumbnail size.

## Stencils

Hold **S** in the viewport to place the stencil:

- drag to move it
- right-drag to scale and rotate it
- **Shift**-drag to change its opacity and contrast

## Pasting images

**Ctrl+V** pastes an image from the clipboard, ready to use as a decal or texture.
