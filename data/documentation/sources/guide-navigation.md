# Moving around

## Default mouse controls

| Do this | To |
|---|---|
| **Alt** + left-drag | Orbit |
| Middle-drag | Pan |
| **Alt** + right-drag | Zoom |
| Mouse wheel | Zoom toward the cursor |
| **F** | Frame the model (or the graph, if the pointer is over it) |

How orbit behaves: on empty space it turns around the whole model. On the model, the closer you are, the more it turns around the exact point you clicked. The wheel and **Alt** + right-drag move the camera toward the spot under the cursor, so you can get right up to small details and paint there. Pan grabs the model: the spot you grab follows the mouse.

## Other control styles

**Preferences > Navigation** offers other layouts if you are used to them:

| Style | Orbit | Pan | Zoom |
|---|---|---|---|
| Default | **Alt** + left | Middle | **Alt** + right |
| Middle-mouse | Middle | **Shift** + middle | **Ctrl** + middle or wheel |
| Alt + wheel | **Alt** + left | Middle | **Alt** + right or wheel |

**N** turns on navigate mode: the left button orbits, middle pans and right zooms, without holding Alt. Press **N** again to go back to painting.

## Views

| Key | View |
|---|---|
| **F1** | 3D view |
| **F2** | 3D and UV side by side |
| **F3** | UV / texture view |
| **M** | Show the full material |
| **Shift+C** | Step through the channels (base color, roughness, metallic and so on) |
| **Tab** | Hide the panels |
| **\\** (hold) | Hide the selected layer to compare before and after |

## Interface size

**Ctrl+=** makes the interface bigger, **Ctrl+-** smaller and **Ctrl+0** resets it to 100%.
