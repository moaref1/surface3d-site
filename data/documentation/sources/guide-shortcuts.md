# Keyboard shortcuts

Every shortcut can be changed in **Preferences > Keymap**. **Ctrl+K** searches every command along with its key. Shortcuts work where the pointer is, so the same key can do different things over the viewport and over Layers.

## General

| Key | Action |
|---|---|
| **Ctrl+K** | Command search |
| **Ctrl+Z** | Undo |
| **Ctrl+=** / **Ctrl+-** / **Ctrl+0** | Interface scale up / down / reset |
| **F2** | Rename (over Layers) |
| **F5** | Brush Settings |
| **Alt** + left-drag | Orbit around the point under the mouse |
| Middle-drag | Pan (default navigation) |
| **Alt** + right-drag | Zoom (default navigation) |

## Paint tools

| Key | Tool |
|---|---|
| **B** / **E** | Brush / Eraser |
| **U** / **K** | Smudge-blur / Clone stamp |
| **G** / **Q** | Fill / Mask brush |
| **I** / **V** | Eyedropper / Decal |
| **P** / **Y** | Spline / Sculpt |
| **Ctrl** + left-drag | Brush size / hardness |
| **Ctrl** + right-drag | Brush rotation / roundness |
| Hold **S** + drag | Move, scale or rotate the stencil |

## Sculpt

| Key | Action |
|---|---|
| **1** to **0** | Strength |
| **Shift+1** to **0** | Depth |
| **Ctrl+[** / **]** | Strength |
| **Shift+[** / **]** | Hardness |
| **X** | Invert (carve / build) |

## Node graph

Hover the graph to use its keys.

| Key | Action |
|---|---|
| **Shift+A** or **F3** | Search and add a node |
| **N** / **B** / **L** / **M** | Add Noise / Blur / Levels / Blend |
| Arrow keys | Select the nearest node in that direction |
| **F** / **F2** / **Space** | Frame / rename / preview |
| **E** | Disable or enable selection |
| **/** or **?** | Show all graph shortcuts |
