# Keyboard shortcuts

These are the default keys in version 0.94. Change any of them in **Preferences > Shortcuts**. **Ctrl+K** searches every command along with its key. Keys work where the pointer is, so the same key can do different things over the viewport and over Layers.

## Everywhere

| Key | Action |
|---|---|
| **Ctrl+N** / **Ctrl+O** | New / open project |
| **Ctrl+S** / **Ctrl+Shift+S** | Save / save as |
| **Ctrl+I** | Import meshes, images, materials or HDRIs |
| **Ctrl+Shift+E** | Export textures |
| **Ctrl+Z** / **Ctrl+Y** | Undo / redo |
| **Ctrl+K** | Search commands |
| **F8** / **F9** | Bake / Paint workspace |
| **F** | Frame the model or graph under the pointer |
| **Ctrl+=** / **Ctrl+-** / **Ctrl+0** | Bigger / smaller / 100% interface |

## Viewport

| Key | Action |
|---|---|
| **Alt** + left-drag | Orbit |
| Middle-drag | Pan |
| **Alt** + right-drag, wheel | Zoom toward the cursor |
| **F1** / **F2** / **F3** | 3D / 3D + UV / UV and texture view |
| **M** | Show the material |
| **Shift+C** | Next channel view |
| **N** | Navigate mode (no Alt needed) |
| **Tab** | Hide the panels |
| **\\** (hold) | Hide the active layer to compare |
| **Ctrl+G** | Group layers |

## Tools

| Key | Tool |
|---|---|
| **B** / **E** | Brush / eraser |
| **U** / **Shift+U** | Smudge / blur |
| **K** | Clone stamp |
| **G** | Fill |
| **Q** | Paint the mask / the material |
| **I** | Eyedropper |
| **V** | Decal |
| **P** | Spline strokes |
| **W** | Particles |
| **Y** | Sculpt |

## Brush

| Key | Action |
|---|---|
| **[** / **]** | Smaller / bigger |
| **Shift+[** / **Shift+]** | Softer / harder |
| **Ctrl+[** / **Ctrl+]** | Rotate the tip by 15 degrees |
| **F5** / **F6** | Brush Settings / Brushes panel |
| **Shift+M** | Mirror X |
| **X** / **D** | Swap / reset colours |
| **Caps Lock** | Precise cursor |
| Hold **S** | Place the stencil |

## Layers panel

| Key | Action |
|---|---|
| **F2** | Rename |
| **Ctrl+D** | Duplicate |
| **Ctrl+C** / **Ctrl+V** | Copy / paste |
| **Ctrl+X** | Cut a sub-layer |
| **Ctrl+E** | Merge |
| **Ctrl+A** | Select all |
| **Up** / **Down** | Previous / next layer |
| **Delete** | Delete |
| **Alt**-click an eye | Show only this layer |

## Sculpt

| Key | Action |
|---|---|
| **X** | Build up / carve in |
| **1** to **0** | Strength |
| **Shift+1** to **Shift+0** | Depth |

## Node graph

| Key | Action |
|---|---|
| **Shift+A** | Add a node |
| **Ctrl** + right-drag | Cut wires |
| **Ctrl+D** / **Delete** | Duplicate / remove |
| **F2** / **Space** | Rename / preview |
| **Ctrl+J** / **Alt+J** | Frame the selection / remove the frame |
| **Ctrl+H** | Hide or show unused inputs |

## Teach mask

| Key | Action |
|---|---|
| Left-drag / right-drag | Here / not here |
| **E** + paint | Erase strokes |
| **Ctrl+Z** | Take back the last stroke |
| **Enter** | Done |
